# 大明湖 · 泉城国风体素世界

基于 **Three.js + Vue 3 + TypeScript + PeerJS** 构建的济南大明湖 1:1 实景国风体素 3D 世界。支持水陆空自由漫游、四季昼夜与明湖秀烟花演出、21 处地标打卡与宣纸明信片、趣味答题解锁四季皮肤与免费武器，以及 WebRTC P2P 好友联机对战（含多人同乘载具、高空跳伞与防空对射）。

## 目录结构

```text
.
├── packages/
│   ├── shared/        # 双端共享类型定义、皮肤/武器/题库静态目录与联机协议
│   ├── engine-core/   # Three.js 3D 引擎内核（地形建筑、载具、弹道碰撞、P2P 房间、国风 BGM）
│   └── web-client/    # Vue 3 + Pinia + Vite Web 端与移动端 HUD（支持 PWA）
├── tests/             # 核心弹道、碰撞、联机与共享目录单元测试
├── scripts/           # 轻量测试运行脚本
├── docs/              # 架构设计与分阶段开发路线图
└── .github/workflows/ # GitHub Pages 自动构建、PR 校验与部署
```

## 快速开始

环境要求：**Node.js >= 20**、**pnpm >= 10**。

```bash
# 安装依赖
pnpm install

# 本地开发（默认端口 5173）
pnpm dev

# 局域网联机调试（暴露本机局域网 IP）
pnpm dev:host

# 全量类型检查
pnpm typecheck

# 运行单元测试
pnpm test

# 构建生产包（输出至 packages/web-client/dist）
pnpm build
```

## 核心特性

- **实景国风大明湖**：涵盖超然楼、历下亭、汇波楼、北极阁、明湖居等 21 处地标打卡，支持春夏秋冬四季切换、昼夜光照、明湖秀水幕烟花与宣纸明信片留影。
- **水陆空载具与多人同乘**：支持敞篷跑车、双人小木船、体素直升机、游船/观光车/摩天轮，支持好友同乘副驾 360° 射击与高空跳伞空降。
- **轻竞技与趣味解锁**：支持单机打鸟抓鱼/AI 对战及 WebRTC P2P 联机（自由混战 / 红蓝对抗），皮肤与武器均可通过趣味古诗/数学答题解锁，内置家长守护定时提醒。
- **双端与离线体验**：PC 键鼠与移动端横屏虚拟摇杆双适配，内置 PWA `manifest.webmanifest` 与 Service Worker 静态资源缓存。
