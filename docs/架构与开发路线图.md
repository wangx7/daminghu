# 大明湖 3D 体素世界 · 架构设计与渐进式开发路线图

> **定位**：基于现有 [大明湖 3D 体素漫游](./index.html) 前端底座，采用**渐进式演进**策略，逐步升级为支持「单机玩法 + 局域网多人组队/对战（单排 & 红蓝对抗）+ Java 企业级社交/商业化后端 + 微信/抖音小游戏二端」的完整全栈项目，并在全流程中实践企业级前后端工程规范。

---

## 一、核心原则与边界决策

1. **双端架构，先 Web 后小游戏**：
   - 因当前为**个人主体（无企业资质）**，微信/抖音小程序不支持 `<web-view>`，因此规划两套前端，**先完成 Web 端（Vue 3 + TypeScript）**，后期再扩展微信/抖音小游戏端。
   - 从 Stage 1 起严格分离**平台无关内核**与**平台 UI 壳**，确保第二套前端复用 70%+ 的 3D 场景、玩法与通信协议代码。
2. **对战放局域网，后端聚焦社交与商业化**：
   - **单排 / 红蓝对抗**等高频实时战斗仅在**局域网**内运行，避免公网后端承担高带宽/高算力战斗同步成本。
   - **Java 后端**专注企业级核心业务：**登录认证、好友/结伴、实时聊天转发（不落库）、付费皮肤商城与订单、免费武器库解锁、结婚/结义关系与大明湖仪式**。
3. **聊天不落库**：
   - 后端 WebSocket 负责实时消息转发（可选 Redis 短期暂存离线消息，拉取即删）；历史聊天记录保存在前端 **IndexedDB**。
4. **个人主体合规变现**：
   - 皮肤支持商业化，武器库坚持免费解锁（打卡/成就/局域网对局获取）。
   - 支付模块采用**策略模式（`PaymentChannel`）**，个人阶段可接入 **爱发电 Webhook / 兑换码 CDKey / 沙箱模拟支付**，未来小游戏端接入**官方流量主激励视频广告**；若后续注册个体户/企业，可无缝接入官方微信/支付宝商户直连。

## 二、总体目录与分层架构

```text
daminghu-project/
├── packages/
│   ├── shared/           # 【双端共享】TS 类型 DTO、皮肤/武器静态配置、API & WS 协议定义
│   ├── engine-core/      # 【双端共享】纯 TS + Three.js 3D 内核（地图、载具、换装、武器弹道、联机插值、婚礼演出）
│   │                     #   约束：禁止直接访问 window/document/localStorage，统一通过 PlatformAdapter 注入
│   ├── web-client/       # 【前端一 · 先做】Vite + Vue 3 + TypeScript + Pinia（PC & 手机浏览器完整版）
│   └── minigame-client/  # 【前端二 · 后做】微信/抖音小游戏（复用 shared + engine-core + three-platformize）
└── backend/              # 【Java 企业级后端】Maven 多模块（对标公司规范，升级现代主流版本）
    ├── daminghu-common/  # 统一返回 R<T>、全局异常、雪花 ID、JWT、工具类（Hutool/Lombok）
    ├── daminghu-biz/     # 业务服务：认证、档案、好友/结义/结婚、皮肤商城与订单、武器库、仪式管理
    ├── daminghu-ws/      # Spring WebSocket：结伴房间、实时聊天转发、在线状态、婚礼现场同步、WebRTC 信令
    └── docker/           # docker-compose.dev.yml / prod.yml、Nginx、Prometheus、Grafana 配置
```

## 三、技术栈选型

### 1. 前端（Web 端）
- **核心框架**：Vue 3 + TypeScript + Vite + Pinia + Vue Router
- **3D 引擎**：Three.js（沿用现有体素渲染、四季/昼夜/明湖秀/宣纸明信片资产）
- **本地持久化**：IndexedDB（聊天记录、离线缓存）+ `localStorage`（基础设置）
- **测试工具**：Vitest（协议/插值单测）+ Playwright（关键流程 E2E）

### 2. 后端（Java 企业级，参考公司 `zhsq-sd` 规范并现代化升级）
- **语言与框架**：Java 17 / 21 (LTS) + Spring Boot 3.3+ + MyBatis-Plus 3.5+
- **鉴权与文档**：Spring Security / Sa-Token + JWT（预留微信/抖音 `openid` 登录）+ Knife4j (OpenAPI 3)
- **数据库与中间件**：
  - **MySQL 8.0**（主库）+ **Flyway**（数据库脚本版本管理）
  - **Redis 7**（Token 状态、在线状态 Presence、房间热态、分布式锁 Redisson、短期离线消息队列）
  - **MinIO（本地）/ 阿里云 OSS 或 Cloudflare R2（线上）**（头像、宣纸明信片/电子婚书图片）
- **工程与运维**：JUnit 5 + Mockito + **Testcontainers**（真实 MySQL/Redis 容器集成测试）、Docker Compose、GitHub Actions CI/CD、Actuator + Micrometer + Prometheus + Grafana、Logback JSON 结构化日志（带 `traceId`）

| 业务域 | 表名 | 核心字段与设计要点 |
| :--- | :--- | :--- |
| **用户与档案** | `t_user` | `id`, `username`, `password_hash`, `wx_openid`, `dy_openid`, `status`, `last_login_at` |
| | `t_user_profile` | `user_id`, `nickname`, `avatar_url`, `title`, `equipped_skin_id`, `equipped_weapon_id`, `stamps_json`（21 景点打卡进度） |
| **皮肤与武器库** | `t_item_catalog` | `id`, `item_type`（`SKIN` 付费 / `WEAPON` 免费）, `name`, `price_fen`（武器恒为 0）, `unlock_rule_json`, `asset_key`, `enabled` |
| | `t_user_inventory` | `id`, `user_id`, `item_id`, `source`（`PURCHASE` / `ACHIEVEMENT` / `CDKEY` / `AD_REWARD`）, `acquired_at`（唯一索引防重复） |
| **商业化订单** | `t_pay_order` | `id`, `order_no`（幂等唯一）, `user_id`, `item_id`, `amount_fen`, `channel`（`SANDBOX` / `AFDIAN` / `CDKEY` / `ALIPAY` / `WXPAY`）, `status`（`UNPAID` → `PAID` → `DELIVERED` / `REFUNDED`）, `external_trade_no`, `paid_at` |
| **社交与深度关系** | `t_social_relation` | `id`, `user_id`, `target_user_id`, `relation_type`（`FRIEND` / `MARRIAGE`）, `status`（`PENDING` / `ACTIVE` / `DISSOLVED`）, `intimacy`, `custom_title`（夫妻关系加唯一约束防重婚） |

| | `t_sworn_member` | `id`, `group_id`, `user_id`, `rank_title`（如大哥/二姐）, `joined_at` |

> **聊天记录不建 MySQL 表**：由后端 WS 实时转发，前端写入 IndexedDB 本地保存。

## 五、个人主体变现方案（收款 & 广告）

| 方式 | 个人主体可行性 | 适用阶段 | 实现建议 |
| :--- | :--- | :--- | :--- |
| **爱发电（afdian）+ Webhook** | ⭐⭐⭐⭐⭐ 合规可用 | Stage 4（Web 端皮肤） | 个人实名即可开通，支持微信/支付宝付款；官方提供 Webhook 回调，可直接对接 Java `t_pay_order` 实现**验签 → 幂等发货 → 背包入库**全流程 |
| **兑换码（CDKey）** | ⭐⭐⭐⭐⭐ 合规可用 | Stage 4（活动/赞助） | 后端生成防伪 CDKey，玩家输入兑换皮肤，顺便练**高并发防刷与分布式锁** |
| **小游戏激励视频广告** | ⭐⭐⭐⭐⭐ 个人最香 | Stage 5（微信/抖音小游戏） | 个人小游戏可直接开通流量主；**看 30 秒激励视频免费解锁限定皮肤/婚礼烟花特效**，结算直接打个人银行卡 |
| **支付宝/微信官方直连支付** | ❌ 需营业执照 | 未来（注册个体户后） | 个人码禁止做线上自动化监控收款（易封号）；若后续业务起量，花极低成本办一张**个体工商户营业执照**即可接入官方商户号，后端通过策略模式零改动接入 |
| **Web 端广告（Google AdSense）** | ⭐⭐⭐ 一般 | 可选 | 个人可申请，但 3D 全屏游戏场景广告位有限，收益不如小游戏激励视频 |

## 六、五阶段渐进式开发计划

### Stage 1：Web 端单机升级（纯前端，零后端）
- 搭建 Monorepo：`packages/shared` + `packages/engine-core` + `packages/web-client`（Vite + Vue 3 + TS + Pinia）。
- 将现有大明湖 3D 世界迁入 `engine-core`，按**国风轻竞技游戏 HUD 规范**（融合梦幻西游 + 刺激战场/和平精英 + 王者荣耀布局）用 Vue 3 重构全部按钮与交互界面。
- 上线**背景音乐（BGM）与音效系统**：梦幻西游式五声音阶国风配乐（白昼漫游 / 夜色超然楼 / 对战鼓点 / 仪式喜乐动态交叉淡入淡出），支持 BGM 与音效独立开关和音量调节。
- 上线**皮肤换装系统**（春夏秋冬 4 套主题皮，含角色外观 + 载具涂装）与**免费武器库**（泉水连发枪、荷花水炮、鹊华长弓/冰晶弹弓，含弹道与命中特效）。
- 增加单机试玩模式（湖面移动靶 / 简单 AI Bot 红蓝试玩），打磨战斗手感。

### Stage 2：Web 端局域网组队 & 对战（单排 + 红蓝对抗）
- 在 `engine-core` 实现 `RemotePlayer` 实体同步（20Hz 状态同步 + 客户端平滑插值 + 载具同步 + 红蓝阵营血条名牌）。
- 实现轻量**局域网房间服务（LAN Host）**：电脑一键启动，同 Wi-Fi 下手机/电脑扫码直连（延迟 <10ms）。
- 上线 3 种局域网模式：**自由结伴漫游**、**单排大乱斗/打卡竞速**、**红蓝对抗（据点占领/积分淘汰）**。
- 局域网内即时气泡聊天与对局结算面板。

### Stage 3：Java 企业级后端起步（登录 → 结伴 → 聊天）
- 搭建 Maven 多模块 Spring Boot 3 + MyBatis-Plus + Flyway + `docker-compose.dev.yml`（MySQL 8 + Redis 7 + MinIO）。
- **里程碑 3.1（登录与档案）**：账号注册/登录、JWT 鉴权、大明湖印章与穿戴状态云端同步。
- **里程碑 3.2（结伴与好友）**：好友申请/列表/在线状态、房间码结伴同游、一键传送到好友身边。
- **里程碑 3.3（实时聊天）**：后端 WS 转发 + Redis 短期离线暂存，前端 IndexedDB 持久化聊天记录。

### Stage 4：皮肤商业化 + 武器库 + 结婚/结义仪式 + 企业级上线
- **皮肤商城与订单**：商品目录、背包系统、完整订单状态机（沙箱支付 + CDKey + 爱发电 Webhook 回调验签与幂等发货）。
- **武器库（免费）**：景点打卡/成就/局域网对局解锁武器，云端同步。
- **结义与结婚仪式**：好友亲密度、金兰谱（多人结义）、夫妻关系 + **大明湖 3D 沉浸式仪式**（预约场次、邀请观礼、画舫巡游 + 超然楼亮灯 + 明湖秀烟花 + 一键生成电子婚书/金兰谱宣纸明信片）。
- **生产级交付**：JUnit 5 + Testcontainers 集成测试、GitHub Actions 自动构建镜像与部署、云服务器（2C4G）Docker Compose + Nginx HTTPS + Prometheus/Grafana 监控。

### Stage 5：第二套前端 —— 微信 / 抖音小游戏
- 新建 `packages/minigame-client`，复用 `packages/shared` 与 `packages/engine-core`（配合 `three-platformize`）。
- 对接微信/抖音小游戏一键登录（复用后端 `openid`）、好友分享卡片、轻量化 Canvas HUD 与**流量主激励视频广告**变现。

## 十、UI 交互与国风 BGM 视听规范

### 1. 游戏级 HUD 重构（融合三款经典游戏优势）
- **借鉴《梦幻西游》—— 国风质感与社交外围**：
  - 视觉语言：宣纸微透磨砂 + 鎏金细描边 + 朱砂印章徽记 + 玉石按钮点击反馈。
  - 布局：左上角角色头像/称号/血条；左下角可折叠聊天气泡窗（世界/队伍/好友频道）；顶部与右侧可收纳国风图标区（皮肤商城、武器库、好友、结义/结婚、景点印章），默认收起保证大明湖视野通透。
- **借鉴《刺激战场 / 和平精英》—— 局内手感与拇指热区**：
  - 左手浮动摇杆（带自动奔跑锁），右手弧形操作轮盘（开火主大键 + 跳跃/翻滚 + 武器 1/2/3 快捷槽 + 上下车/氮气加速），顶部**方向罗盘条**（标示景点、队友、红蓝据点方位）+ 右上角高清导览小地图。
- **借鉴《王者荣耀》—— 对战反馈与仪式感**：
  - 对战模式顶部显示**红蓝比分条 + 倒计时 + 据点占领进度**、清晰利落的击杀/占点播报条、匹配准备确认弹窗、赛后 MVP 与战绩结算卡片。

### 2. 背景音乐（BGM）：梦幻西游同款听感（原创无版权风险）
